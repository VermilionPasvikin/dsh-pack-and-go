## 0. 任务流转规则

- 状态标记：`✅ 已完成` / `🟨 进行中` / `⬜ 未开始` / `➖ 暂缓` / `⛔ 阻塞（需 ADR）`。
- **前置写法**：任务 ID（`T1.2`）、里程碑 ID（`M1`，表示该里程碑**全部**任务 ✅）、逗号列表（`T5.2, T5.3`）；范围仅用于里程碑（`M1–M3`）。
- 取任务顺序：按里程碑编号、任务编号**升序**扫描；跳过 `✅/➖/⛔`；只取“所有前置均为 ✅”的**第一个** `⬜`。
- 完成一个任务必须同时做三件事：① 本表状态改 `✅` 并填完成日期；② `DEVLOG.md` 追加一条（编号递增）；③ 一次 commit（信息末尾带 `(devlog NNN)`）。
- 当前里程碑全部 `✅` 时，先执行该里程碑的 **DoD 验收**（§1 表），通过后才进入下一里程碑。
- 任务需要变更范围/顺序时：先写 ADR，再改本表；不改写历史条目。
- 没有可执行任务时：报告阻塞原因并停止，**不自行扩大范围**。
