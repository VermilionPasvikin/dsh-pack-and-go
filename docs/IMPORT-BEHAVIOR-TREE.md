## 2. 工作区落点（包内每个 workspace）

| 节点 | 条件 | 当前行为 | 状态 |
|---|---|---|---|
| 2.1 | `<目标>/<标题>` 不存在 | 创建目录 + 登记新工作区 | ✅ |
| 2.2 | `<目标>/<标题>` 已存在（之前导入） | 复用已有工作区（同路径），不改标题 | ✅ |
| 2.3 | 标题与其他工作区重名（不同路径） | 登记名加「（导入 N）」 | ✅ |

| 2.5 | 工作区文件与目标目录已有文件同名 | **覆盖写**（无提示） | ⚠️ 待定：覆盖/跳过/报错？ |

| 2.7 | 目标目录路径过长/含非法字符 | 创建/写入失败 → 红字 | ✅ |

## 3. 会话冲突（包内每个 session）

| 节点 | 条件 | 当前行为 | 状态 |
|---|---|---|---|
| 3.1 | 同 id 不存在 | 写入到 `<目标>/<标题>` 下的会话目录；cwd 改写 | ✅ |
| 3.2 | 同 id 已存在 + 跳过 | 不写，计入「跳过」 | ✅ |
| 3.3 | 同 id 已存在 + 覆盖 + **现有 cwd 已知** | 对齐现有 cwd **原地覆盖**（恢复，不写第二份） | ✅（本轮修复） |
| 3.4 | 同 id 已存在 + 覆盖 + 现有 cwd **未知** | 按目标 cwd 写 → 可能产生重复 id（DSH 启动失败） | ⚠️ 待定：应拒绝覆盖？ |
| 3.8 | 同 id 已存在 + 覆盖 + **目标目录 ≠ 现有 cwd** | **迁移覆盖（已定 C）**：备份并移除旧位置同 id 目录 → 写入目标 cwd（包内版本）→ 结果提示「已迁移覆盖：<原工作区>/<会话> → <新工作区>/<会话>」 | ✅ 已拍板 |
| 3.5 | 会话无 workspaceKey（纯对话包） | cwd 保持源路径，落到「未分组」 | ⚠️ 待定：是否也落到目标目录？ |
| 3.6 | 会话文件被 DSH 占用/锁定 | 写入失败 → 红字 | ✅ |
| 3.7 | 包内父会话被跳过、子会话导入（fork 链） | 子会话 parentSession 指向包内父 id | ⚠️ 待定：是否跟随父策略 |

## 7. 决策点（已定，2026-11-11，用户采纳全部建议）

> **迁移覆盖（C）**：会话冲突 + 新目录落点 → 备份移除旧目录、写入新目录，结果明确提示「原工作区/会话 → 新工作区/会话」。

| # | 决策 | 已定行为 |
|---|---|---|
| 1 | 旧格式包（<4） | 直接写文件，结果提示「旧格式，打开时自动迁移」 |
| 2 | 目标目录内已有同名目录（非本插件创建） | 新建 `标题 (1)`，不复用用户目录 |
| 3 | 工作区文件同名冲突 | 覆盖写，结果统计「覆盖 N 个文件」 |
| 4 | 附件同名冲突 | 覆盖（内容寻址） |
| 5 | 覆盖但现有 cwd 未知 | 拒绝覆盖 + 红字提示 |
| 6 | 纯对话包（无 workspaceKey） | cwd 保留源路径，结果提示「N 个未归组」 |
| 7 | 被跳过会话的附件 | 不恢复（只恢复实际写入会话引用的附件） |
| 8 | 目标目录 = 源路径 | 允许（复用工作区，原地恢复） |
| 9 | 包内工作区无有效会话 | 不还原该工作区文件、不登记工作区 |
| 10 | fork 链父子 | 父被跳过 → 子强制跳过 |
