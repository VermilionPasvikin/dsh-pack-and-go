# 黑盒验收用例（v0.3 全功能）

> 环境：一次性 profile `http://127.0.0.1:3080/?token=<每次启动打印>`；版本标记应为 `b2110-2235`（浮层底部小字）。
> 准备：桌面建可写目录（示例 `C:\Users\15349\Desktop`）；一次性 home 内已有若干对话。

## A 入口与浮层

| ID | 步骤 | 预期 |
|---|---|---|
| A1 | 打开页面，看左侧栏底部 | 有「迁移对话或工作区」按钮（窄栏时仅图标，悬停有提示） |
| A2 | 点击该按钮 | 打开浮层；显示标题、副标题、导出/导入 Tab、工作区树 |
| A3 | 拖动浮层标题栏 | 浮层跟随移动 |
| A4 | 点 ×、Esc、点遮罩 各一次 | 三种方式都能关闭 |
| A5 | 设置页 →「迁移」section → 点「打开迁移面板」 | 打开浮层并关闭设置面板 |
| A6 | 关闭后再次打开 | 树重新加载，无报错 |

## B 主题与语言

| ID | 步骤 | 预期 |
|---|---|---|
| B1 | 深色主题查看浮层 | 背景/文字/输入框/按钮与 DSH 深色主题一致，无白底黑字 |
| B2 | 切换语言为英文 | 按钮、标题、Tab、提示文字变英文 |
| B3 | 切回中文 | 恢复中文 |

## C 导出：选择树

| ID | 步骤 | 预期 |
|---|---|---|
| C1 | 打开导出 Tab | 显示工作区（标题/路径/对话数）与对话列表 |
| C2 | 勾工作区行 | 该组对话全选；底部统计「已选 1 个工作区 · N 个对话」 |
| C3 | 取消组内一个对话 | 组行变半选（indeterminate） |
| C4 | 不勾组、只勾一个对话 | 统计只算该对话 |
| C5 | 对话 >20 时 | 出现搜索框；输入标题片段可过滤，清空恢复 |
| C6 | 工作区行点「只带文件」 | 该组只保留首个对话自动勾选，「将工作区一并导出」勾上 |
| C7 | 勾「显示已归档」 | 出现说明（归档会话暂不参与导出） |

## D 导出：执行与完成

| ID | 步骤 | 预期 |
|---|---|---|
| D1 | 不选任何内容 | 「开始打包」禁用，显示提示 |
| D2 | 选 1 个对话，路径填桌面目录，开始打包 | 按钮转圈；成功卡片显示包路径/大小/耗时；桌面出现 1 个 `dsh-mover-*.dshpack` |
| D3 | 立刻再导出另一个对话 | 不出现 `write after end`；桌面只多 1 个包，没有半截残留 |
| D4 | 填完整文件名（如 `Desktop\my.dshpack`） | 生成该名称的包 |
| D5 | 填不存在父目录（如 `Z:\nope\x.dshpack`） | 红色错误；桌面无产物 |
| D6 | 导出成功后点「复制路径」 | 剪贴板可粘贴出包路径 |
| D7 | 关闭浮层再打开 | 上次完成卡片清空 |

## E 导出：高级选项

| ID | 步骤 | 预期 |
|---|---|---|
| E1 | 展开「高级选项」 | 全量打包 / 不压缩 / 导前预检 / 额外排除 / 包含附件 可见 |
| E2 | 勾「全量打包」+「将工作区一并导出」 | 包内包含通常被排除的目录（包变大） |
| E3 | 同一内容分别「不压缩」与默认 | 不压缩包体积明显更大 |
| E4 | 勾「导前预检」导出 | 结果文本末尾出现「预检 N 项」 |
| E5 | 额外排除填 `.cache` | 包内不含该目录 |
| E6 | 勾「包含附件」（选带图片/文件的会话） | 包内出现 `attachments/` 条目 |

## F 导入：选择与预览

| ID | 步骤 | 预期 |
|---|---|---|
| F1 | 打开导入 Tab | 包路径输入、「选择文件」「预览」按钮 |
| F2 | 点「选择文件」→ 选包所在目录 | 目录内 1 个包自动填入；多个包显示列表，点选填入 |
| F3 | 点「预览」 | 显示来源平台/DSH 版本/包大小/对话/工作区/附件数/冲突数 |
| F4 | 预览后正常导入 | 导入成功 |
| F5 | 预览不存在的包 | 红色错误 |
| F6 | 选择无 `.dshpack` 的目录 | 提示该目录没有迁移包 |

## G 导入：落点与执行

| ID | 步骤 | 预期 |
|---|---|---|
| G1 | 看落点默认为「放回原路径」 | 默认选中 |
| G2 | 切「指定目录」 | 出现目标目录输入框 |
| G3 | 放回原路径导入 | 成功；结果含「工作区映射」 |
| G4 | 指定目录导入（如桌面某目录） | 文件出现在指定目录 |
| G5 | 导入损坏/截断包（可复制一个包后截断一半） | 红色错误「不是有效的 zip」 |

## H 导入：结果与冲突

| ID | 步骤 | 预期 |
|---|---|---|
| H1 | 首次导入新包 | 结果「已导入 N 个对话（覆盖 0 个）、跳过 0 个…」 |
| H2 | 重复导入同一包 | 结果「跳过 N 个已存在」，不产生重复 |
| H3 | 导入带工作区的包 | 结果含映射表（原路径 → 目标路径） |
| H4 | 导入带附件的包 | 结果含「附件 N 个」 |
| H5 | 点击导入后观察按钮 | 处理中禁用，无法重复提交 |
| H6 | 导入成功提示 | 含「若左侧列表未出现，请刷新页面或重启 DSH」 |

## I 附件

| ID | 步骤 | 预期 |
|---|---|---|
| I1 | 导出带附件，用 7-Zip/资源管理器查看包 | 包含 `attachments/` 条目 |
| I2 | 导入该包 | 结果附件数 >0；会话内图片/文件可读 |
| I3 | 导入后检查 `%DSH_HOME%\attachments\v1` | 附件对象已恢复 |

## J 命令入口（可选，聊天框）

| ID | 命令 | 预期 |
|---|---|---|
| J1 | `/mover list` | 返回含 meta/workspaces/sessions 的 JSON |
| J2 | `/mover export "D:\test.dshpack"`（不带 id = 全部对话） | 生成包 |
| J3 | `/mover find "D:\"` | 列出该目录下 `.dshpack` |
| J4 | `/mover size "<目录>"` | 返回字节数与文件数 |
| J5 | `/mover inspect "<包>"` | 返回摘要 JSON |
| J6 | `/mover import "<包>" --original` | 放回原路径导入 |

## K 异常与边界

| ID | 步骤 | 预期 |
|---|---|---|
| K1 | 主题切换（深→浅）后再打开浮层 | 配色跟随，无异常 |
| K2 | 语言切换后重新打开浮层 | 文案跟随 |
| K3 | 无会话的全新 home（可选） | 主按钮禁用并提示无上下文 |
| K4 | 浮层打开时在树内滚动 | 仅树区域滚动，卡片不撑破屏幕 |
| K5 | 导出/导入进行中关闭浮层再打开 | 无崩溃；结果以最终状态显示 |
| K6 | 长路径/含空格路径（如 `C:\Users\15349\Desktop\a b\c.dshpack`） | 正常生成/导入（引号处理正确） |
